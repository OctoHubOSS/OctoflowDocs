Every command is a Discord slash command (`/command`). There is no prefix command anymore — older messages mentioning a `git!` prefix are out of date.

Most commands require the **Manage Server** (`MANAGE_GUILD`) permission and are guild-only. [`/restore`](/docs/commands/backups/restore) is a notable exception — see its page for details.
